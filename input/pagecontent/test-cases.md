### How these pages are generated

Each Test Case page is rendered directly from its `TestScript` resource by
[fhir-frog](https://gitlab.com/fhirfrog/fhir-frog)'s
`fhir-frog-testscript-render` module - the same narrative-first content
model `frog-runner`'s own UI uses for execution results, just applied here
to the test *definition* rather than a run's outcome. They're generated by
a CI step that builds that module from `fhir-frog`'s `main` and runs it
against this repo's `input/resources/`, and the resulting `.md` files are
committed to this repository (regenerated and re-committed whenever
`input/resources/` or `fhir-frog`'s renderer changes) - see
`docs/planning-strategy.md` for the full mechanism.
